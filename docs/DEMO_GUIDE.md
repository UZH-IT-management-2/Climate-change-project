# Five-minute demonstration guide

1. Open the deployed site or run `npm run serve` and open the local URL.
2. Explain that the map uses official MeteoSwiss annual grids from 1961–2025.
3. Keep **Mean temperature** selected and drag the timeline from 1961 to a recent year.
4. Press **Play**; show the year and climate layer advancing, then press **Pause**.
5. Select **Difference** and explain the arithmetic 1961–1990 reference mean.
6. Select **Precipitation**, then **Sunshine**, and point out the fixed legends and units.
7. Select **Hot days**. Click Zürich/Fluntern or Lugano to show the official count,
   baseline, difference, and station-history sparkline.
8. Switch the language to German, French, or Italian; note that the map view remains.
9. Open **About** and show methodology, limitations, attribution, and privacy.
10. End with the architecture: offline Python processing plus a static HTML/CSS/JS site.

Do not present snow, monthly views, Firefox/Edge checks, or client acceptance
unless they have subsequently been completed and verified.
